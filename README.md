# Планувальник

Планувальник дня: погодинний розклад, задачі на день (без часу), нотатки
й нагадування, плюс календар і смужка з сусідніми днями.
Застосунок лише для телефона (Android), мова інтерфейсу — українська.
На комп'ютері є окремий застосунок; спільна з ним лише база Supabase.

Стек: **Tauri 2 + React + TypeScript + Tailwind CSS + Supabase**
(Postgres + автентифікація). Дані зберігаються в хмарі. Без мережі
застосунок показує раніше завантажені дні з кешу, а галочки й нотатку дня
складає в чергу і надсилає, коли мережа повернеться; решта змін без мережі
недоступна. Нагадування заплановані наперед і приходять без мережі.

## Крок 1 — створіть проєкт Supabase (безкоштовно)

1. Зареєструйтесь на https://supabase.com і натисніть **New project**.
2. Дайте проєкту будь-яку назву, задайте пароль бази даних (збережіть
   його на всякий випадок, хоча в коді він не використовується), оберіть
   регіон (найближчий до вас) і натисніть **Create new project**.
   Створення займає десь хвилину.
3. У лівому меню відкрийте **SQL Editor** → **New query**, вставте туди
   весь вміст файлу `supabase/schema.sql` з цього проєкту і натисніть
   **Run**. Це створить усі таблиці й налаштує захист даних (RLS) —
   кожен користувач бачитиме тільки свої записи.
4. Так само по черзі запустіть міграції — див. розділ «Міграції» нижче.
5. У лівому меню відкрийте **Project Settings** → **API**. Скопіюйте:
   - **Project URL** (виглядає як `https://xxxxx.supabase.co`)
   - **anon public** ключ (довгий рядок під "Project API keys")

## Крок 2 — підключіть застосунок до вашого проєкту

У корені проєкту (поряд з `package.json`) створіть файл `.env`
(скопіюйте `.env.example` і перейменуйте) і вставте туди свої значення:

```
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=ваш-anon-public-ключ
```

Файл `.env` не потрапляє в git (він вже в `.gitignore`) — це ваш
приватний ключ доступу до вашої ж бази.

## Крок 3 — встановлення й запуск

```bash
npm install
npm run tauri android dev
```

При першому запуску застосунок покаже екран входу. Натисніть
"Немає акаунту? Зареєструватись", введіть пошту й пароль. Supabase
надішле лист із підтвердженням на пошту (перевірте й Спам) —
підтвердіть і після цього можна входити.

Інші команди:

- `npm run dev` — лише веб-частина в браузері (без нагадувань).
- `npm run tauri android build` — APK.
- `npm run build` — перевірка типів і збірка; запускати після кожної зміни.

## Що потрібно встановити перед першим запуском

1. **Node.js** 18+ — https://nodejs.org
2. **Rust** — https://www.rust-lang.org/tools/install
3. Системні залежності Tauri —
   https://tauri.app/start/prerequisites/
4. **Android Studio** з SDK і NDK, а також Rust-цілі:
   `rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android`

## Міграції

Зміни бази після `schema.sql` лежать окремими файлами
`supabase/migration_*.sql`. Кожен запускається один раз у **SQL Editor**
(вставити → **Run**); повторний запуск безпечний.

| Файл | Що додає |
| --- | --- |
| `migration_reminders.sql` | поля задачі `remind` і `remind_before_min` (власні нагадування задачі) |
| `migration_series.sql` | поле `series_id` — повторювані задачі |
| `migration_create_tasks.sql` | функція `create_scheduled_tasks` — задача з підзадачами однією транзакцією (спершу `migration_reminders.sql` і `migration_series.sql`) |
| `migration_multi_day_tasks.sql` | таблиця `multi_day_tasks` — задачі на кілька днів |

Застосунок працює і без запущених міграцій — просто без відповідних
можливостей. `supabase/seed_training_plan.sql` — не міграція, а
необов'язковий план тренувань для імпорту.

## Android

Android-проєкт уже згенеровано в `src-tauri/gen/android`
(пакет `com.planuvalnyk.app`). **Не запускайте `tauri android init`
повторно** — він перезапише нативний код нагадувань.

```bash
npm run tauri android dev     # на телефоні (USB-налагодження) або емуляторі
npm run tauri android build   # APK
```

Готовий APK з'явиться в `src-tauri/gen/android/app/build/outputs/apk/`.
Для підписаної релізної збірки потрібен
`src-tauri/gen/android/keystore.properties` (не потрапляє в git).

Версії `tauri` (Rust) і `@tauri-apps/api` (npm) мають збігатися до
мінорної, інакше збірка Android зупиниться з помилкою.

## Нагадування

Що й коли нагадувати, визначає `src/lib/reminderPlan.ts` за налаштуваннями
й полями задачі; план будується на 7 днів наперед і оновлюється при
відкритті застосунку, зміні задач і налаштувань.

Власний плагін `reminders` (Kotlin, `src-tauri/gen/android/
app/src/main/java/com/planuvalnyk/app/`): точні будильники `AlarmManager`
і сповіщення з власним макетом (кружок категорії, деталі, кнопки
«Виконано» і «Відкласти на 10 хв»). «Виконано» записує задачу в базу
одразу, а якщо не вийшло — при наступному відкритті застосунку.
Після перезавантаження телефона будильники відновлюються.

На Xiaomi/Poco (HyperOS/MIUI) для вчасних нагадувань увімкніть для
застосунку **Автозапуск** і **Економія заряду → Без обмежень**.
Діагностика: Android Studio → Logcat, фільтр `tag:Reminders`.

## Налаштування

Екран налаштувань (шестірня вгорі) зберігає параметри нагадувань
на самому пристрої (`localStorage`):
головний вимикач, за скільки хвилин попереджати, нагадування в момент
початку, категорії, режим звуку, тихі години, ранковий план і вечірній
підсумок, перекус перед вечірнім тренуванням і пульс після нього.
Там же — тестове сповіщення й список найближчих нагадувань.

## Структура проєкту

```
src/
  App.tsx           — корінь: вхід, головний екран, перепланування нагадувань
  components/       — екрани й елементи інтерфейсу (SettingsScreen, AddTaskModal, Toaster…)
  hooks/            — useDayData (дані одного дня), useWeekSummaries (тиждень)
  db/database.ts    — весь доступ до Supabase
  lib/reminderPlan.ts — план нагадувань (чиста функція buildPlan)
  lib/reminders.ts  — доставка плану: системні сповіщення на телефоні
  lib/settings.ts   — налаштування нагадувань (localStorage)
  lib/supabaseClient.ts — клієнт Supabase, читає ключі з .env
  types.ts          — типи й назви категорій
supabase/           — schema.sql і міграції migration_*.sql
src-tauri/          — Rust-обгортка Tauri; gen/android — Android-проєкт
```
