# Планувальник (planuvalnyk-mobile)

Планувальник дня: розклад за годинами, задачі дня без часу, нотатки, нагадування.
Працює на комп'ютері (Windows) і на Android. Мова інтерфейсу — українська.

## Стек

- Tauri 2 (Rust-обгортка в `src-tauri/`), React 18, TypeScript, Tailwind CSS 3, Vite.
- Дані: Supabase (Postgres + авторизація). Без інтернету застосунок даних не показує.
- Android-проєкт: `src-tauri/gen/android`, пакет `com.planuvalnyk.app`.

## Команди

- `npm run dev` — лише веб-частина у браузері.
- `npm run build` — перевірка типів і збірка (`tsc && vite build`). Запускати після кожної зміни.
- `npm run tauri dev` — застосунок на комп'ютері.
- `npm run tauri android dev` — застосунок на телефоні або емуляторі.
- `npm run tauri android build` — APK.

## Структура

- `src/App.tsx` — корінь: авторизація, головний екран, перепланування нагадувань.
- `src/components/` — екрани й елементи інтерфейсу.
  - `SettingsScreen.tsx` — налаштування; `AddTaskModal.tsx` — створення і редагування задачі.
  - `Toaster.tsx` — картки-повідомлення всередині застосунку.
- `src/hooks/useDayData.ts` — дані одного дня; `useWeekSummaries.ts` — тиждень.
- `src/db/database.ts` — увесь доступ до Supabase. Інші файли до бази напряму не ходять
  (виняток: `src/lib/reminders.ts` читає задачі на 7 днів наперед).
- `src/lib/settings.ts` — налаштування нагадувань, зберігаються в `localStorage` пристрою.
- `src/lib/reminderPlan.ts` — чиста функція `buildPlan`: задачі + налаштування → список нагадувань.
- `src/lib/reminders.ts` — доставка плану: системні сповіщення на телефоні, картки на комп'ютері.
- `src/lib/toast.ts` — сховище карток-повідомлень.
- `src/types.ts` — типи й назви категорій.
- `supabase/schema.sql` — схема бази; `supabase/migration_*.sql` — подальші зміни.
- `tailwind.config.js` — кольори (`canvas`, `panel`, `line`, `ink`, `muted`, `accent`, `category.*`).

## Правила роботи

1. Один логічний крок — один коміт. Повідомлення комітів українською.
2. Після кожного кроку: `npm run build`. Зміни, що стосуються Android, перевіряти
   через `npm run tauri android dev`.
3. Тексти інтерфейсу й коментарі в коді — українською, у стилі наявних.
4. Зміни в базі — тільки окремим файлом `supabase/migration_<назва>.sql`. Код має працювати
   і тоді, коли міграцію ще не запущено (приклад: поля `remind` у `database.ts`).
5. Не запускати `tauri android init` повторно: він перезапише `src-tauri/gen/android`.
6. Нові залежності — тільки якщо без них ніяк; перед додаванням запитати.
7. Не чіпати `.env` і не комітити ключі.
8. Стиль: Tailwind-класи з наявної палітри, картки `rounded-xl2 border border-line bg-panel shadow-card`.
   Нові кольори додавати в `tailwind.config.js`, а не писати hex у компонентах.
9. Логіку «що і коли нагадувати» змінювати тільки в `reminderPlan.ts`; `reminders.ts` лише доставляє.
10. Картки всередині застосунку (`toast`) — тільки для помилок і результатів дій у налаштуваннях.
    Про додавання чи видалення задачі не сповіщати.
11. Якщо щось у плані незрозуміле або документація Tauri розходиться з планом — зупинитися й запитати.

## Поточна робота

План і стан виконання: `PLAN.md`. Перед початком прочитати його й продовжити з першого
невідміченого пункту. Після завершення пункту поставити галочку в `PLAN.md` у тому самому коміті.
